# 排班场次归档

目标：读取用户指定的排班表，按已确认的推流与排班分组映射生成场次，文档以用户身份放到指定文件夹，在新 Base 表保存链接。

- 新建表已完成：tblcnhzKQ6Ivv9VS，13 个字段。
- `duty_schedule.py`：解析当前整体排班布局，年份来自同表明确的完整日期；不猜年份，不将空排班或运营当主播。单元格原文保留，姓名不做通讯录推断。
- `scheduled_export.py`：读取最新工作簿尺寸和排班，按日期及明确映射选择已结束场次；拉取所有重叠转写片段，未完成则暂缓。默认只预览，--apply 执行写入。
- `session_export.py`：保留不可变快照与不确定写入保护，增加排班元信息、指定目录、边界音频提示。
- 配置仅包含非敏感资源 token，推流映射确认前为空，不自动猜京东与天猫相同。
- 验证：日期锚点、跨午夜、空排班、分组过滤、重复场次、跨班片段、人员与链接字段；真实测试音频写入文档和新表并回读。
