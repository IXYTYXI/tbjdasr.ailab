- 真实飞书 HTTP 分片测试：现有应用可调用；测试语音首个非空响应约 1.4–1.7 秒（从调用开始计时，不代表 OBS 端到端延迟）。响应是累计且可修订的文字，stream_id 实际带租户前缀，结果 sequence_id 可重复和滞后。

- 过程中飞书曾返回 10024/qps exceeded；冷却后恢复。已覆盖 10024、99991400、HTTP 400/429 及恢复时间头，至少冷却 60 秒，不保证租户限流永不发生。
