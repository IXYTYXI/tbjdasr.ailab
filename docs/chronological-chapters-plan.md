# 每日文档按交班时间分章

用户要求：每日一份文档，按实际排班时间顺序分章；换人新增一章，同一主播间隔后再次上场仍是新章。小时录制策略不变。

实现：从当日排班合并同直播间、同主播且连续的时段，给原始场次补充 chapter_since/chapter_until，Base 仍保留原场次记录。每日文档使用时间范围＋人员为章节标题。新增章节按开始时间插入正确位置，晚到的转写按录音时间插回原章节内部；不因 ASR 完成顺序改变阅读顺序。北京时间午夜结束明确写成次日00:00。

步骤：先补章节排序、段落排序和连续排班合并测试，再实现 timeline_documents.py 与网关的定点插入，接入同步服务；完整回归后创建真实飞书验收文档，故意乱序写入验证结果；推送并重启飞书同步服务，录制进程不重启。

旧的按主播分章文档保留原文，不在此次自动重排历史内容。新场次默认按时序分章；实际部署前检查是否已存在需要迁移的当日文档。
