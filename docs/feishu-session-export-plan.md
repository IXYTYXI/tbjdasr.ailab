# 场次文档和多维表格索引

目标：以用户身份将一个直播场次的完整逐字稿写入指定飞书文件夹，再将场次信息和文档链接写到用户选定的多维表格。默认文件夹沿用 ZvZ0fN9YdlYt26dGCMDcDjo3nMc。

现有 export_feishu.py 按可变任务快照摘要建文档，不能代表稳定场次且没有多维表格回写。新增场次导出入口，使用明确 session-id、room、since/until 定义边界；缺少自动开停播事件时不伪称能够准确恢复场次。目标 Base 待用户提供链接或明确新建。

实现步骤：
1. 写测试验证稳定场次重复调用不重复创建、表格失败可重试、文档写入不确定时停止以免重复追加、未完成片段拒绝最终归档。
2. 实现场次导出器：文档分段写入，进度持久化；完成文档后写 Base 记录；保留中间状态与映射；记录创建返回不确定时禁止自动重复创建。
3. 使用 --as user 调用 lark-cli；写入前检查真实字段结构，标题/XML内容转义。
4. 提供管理端脚本与操作说明；读取已有 API 获取场次转写。保留原 TXT 输出及原导出脚本。
5. 获得 Base 目标后使用真实转写的合成语音测试完成一次文档+记录联调，回读检查；不把测试场次标为正式直播。

边界：本次场次导出支持显式时间范围；自动按开播/停播或断线合并划分需结合用户确认的规则实施。服务器当前没有 lark-cli 用户授权的证据，不擅自复制本机用户凭据到服务器。
